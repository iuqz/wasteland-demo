# 末日战车 · Wasteland Demo

这是《末日战车》网页版试玩仓库，目标使用 GitHub Pages 以静态网站方式发布。

主页：<https://iuqz.github.io/wasteland-demo/>

## 发布说明

将完整的网页试玩文件放在仓库根目录，其中必须有 `index.html`、`battle.html`、`garage.html`，以及 `assets/`、`models/`、`design/data/` 下的资源文件。

然后进入仓库 **Settings → Pages**，选择 **Deploy from a branch** → `main` → `/(root)` 并保存。

当前仓库仅初始化发布设置；请不要把未上传完整资源的页面误认为可玩版本。
